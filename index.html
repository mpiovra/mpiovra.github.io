Personal backup utility

Studio Save

A private command-line tool for creating encrypted, versioned checkpoints of creative and software projects.

What it does

Studio Save keeps recoverable project snapshots on the owner's computer and can copy encrypted backup data to owner-managed storage. Backup contents are encrypted before they leave the computer. The Google Drive connection, when enabled, is used only for storing that encrypted backup data.

Studio Save is maintained for personal use by one owner. It is not a hosted backup service and is not offered to other users.
